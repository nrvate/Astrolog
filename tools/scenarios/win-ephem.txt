# The Windows half of Ephemeris Settings (QT_GUI_PLAN.md items 286-287):
# the dialog opens from Setting / Ephemeris Settings, every source in the
# list can be picked and shows its own rows, a row with focus says what
# leaving it empty means, Test runs and the dialog survives it, and Escape
# closes it. The Qt suite asserts what Test SAYS; Wine has no way to read
# a static control's text, so the shots are for looking at, and the expect
# lines are what this scenario proves.
expect-window Astrolog
focus Astrolog
# By arrows, not "p": E&phemeris shares its letter with &Planetary Moons,
# because every letter of "Ephemeris Settings" is already some other
# Setting item's (QT_GUI_PLAN.md item 286), and "p" lands on the submenu.
# The menu opens on its first item; Up wraps to Display Settings, and Up
# again is Ephemeris Settings.
menu s Up
key Up
key Return
expect-window Ephemeris Settings
focus Ephemeris Settings
shot out/win/ephem-0-open.png
